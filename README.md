🐍 **Python Projetos - Mundo 1**

*Repositório dedicado ao desenvolvimento e estudo de Back-End, dados e I.A utilizando Python.*

Esses projetos foram feitos com base nos meus conhecimentos adquiridos no curso de Python Mundo 1 do Gustavo Guanabara (Curso em Vídeo).

Aqui estão reunidos projetos práticos voltados para construção de lógica de programação, validação, cálculos, conversão e etc. Tudo de forma simples, de nível iniciante.

O objetivo deste repositório é consolidar conhecimentos em desenvolvimento python/back-end, aplicando conceitos importantes como lógica de programação, organização de código e alguns conceitos matemáticos em forma de código.


🚀 **Objetivos do Repositório:**

-Praticar lógica de programação com Python

-Aplicar boas práticas de organização de código

-Evoluir progressivamente para projetos mais complexos
